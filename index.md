## Easy Kanban

Easy Kanban is a minimal, self-hosted personal task board designed to keep projects, tasks, and subtasks in one clear place[cite: 2]. Built to avoid clutter, it features real-time cloud sync powered by a personal Neon database, board data conflict protection, JSON backup/restore, custom themes, and a private deployment gateway[cite: 2].

## Qur'anic Arabic Cognate & Lexicon Portal

The Qur'anic Arabic Cognate & Lexicon Portal is an interactive tool for comparative Semitic lexicography[cite: 1]. It bridges Qur'anic Arabic roots to their Hebrew cognates using historical sound-change rules and pulls live dictionary definitions directly from Sefaria and Wiktionary[cite: 1]. 

It also serves as a unified search hub for major Qur'anic corpora and classical lexicons (including Lane's Lexicon via Ejtaal, The Quranic Arabic Corpus, and Al-Ma'any), eliminating the need to manually cross-reference multiple platforms[cite: 1].

→ [View project on GitHub](https://github.com/barqx/quran-cognate-lexicon){:target="_blank"}

## Pak Urdu Phonetic

Pak Urdu Phonetic is an Urdu keyboard layout faithfully ported from the popular Windows-based Pak Urdu Installer layout by mBilalm[cite: 1]. It offers the same simple, intuitive phonetic typing experience and brings this widely adopted standard to the Keyman platform for cross-platform use[cite: 1].

With over 160+ unique key mappings across regular, Shift, AltGr (Right Alt), and Shift+AltGr combinations, this layout offers the most complete phonetic Urdu typing solution available – more comprehensive than any previous Urdu keyboard layout to date[cite: 1].

→ [View project on GitHub](https://github.com/barqx/pak-urdu-phonetic){:target="_blank"}  
→ [Installation instructions and keymap](https://barqx.github.io/pak-urdu-phonetic){:target="_blank"}
